## Method used (and corrections to method.md)

- The manifest has no per-file `bucket` field. Bucket 3 = `buckets[]` entry with `id: 3` (third in order), matched by directory prefix; 59 files, matches `fileCount`.
- Fork delta was computed after normalizing base/ours/theirs with `oxfmt` and removing comments (TypeScript printer). This removes the 100-column reformat and the Chinese-to-English comment churn. `forkCodeDiffSize` in the manifest overstates the real delta (for example `botsUi` 19 -> 0, `useCodingPlanProducts` 121 -> 0).
- Correction: for files where upstream barely changed (`MemorySettingsViewer`, 2 upstream lines), the fork file is the start, plus upstream's line. Not a blind checkout.
- Correction: an upstream import path move (`@zcode/shared` -> `@zcode/shared/test-ids`) is part of theirs and must be kept, not reverted to the fork import.
- Test files: upstream already English-ized many test names and cases. Upstream test content is kept; fork-added cases are listed below.
- `.staged-file-size-exemptions` block: `# TEMPORARY upstream 3.16.1 sync (ui bucket 3)`.
