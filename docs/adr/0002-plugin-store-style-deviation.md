# The Plugin Store Intentionally Deviates from the Restrained Style of DESIGN.md

The repository design system (DESIGN.md) says to avoid "marketing-style spacing, playful gradients, bright full-surface brand fills". The 2026-07 plugin store redesign is an explicit product decision to use a showcase-store look and interaction: display-size headings, generous whitespace, hero gradient banners, example-prompt pills.

The deviation is **limited to plugin-store surfaces** (list page, detail page, manage-installed view). It is not a precedent for other settings pages or the global UI. Store pages must still use the existing semantic tokens for light/dark themes and Chinese/English adaptation.

If the design system and the store style conflict in future, this decision wins. Do not "fix" the store pages' whitespace and gradients in passing.
