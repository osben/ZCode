# OpenRouter Attribution Headers

OpenRouter app attribution requires OpenRouter-specific title and category headers so requests through OpenRouter or compatible gateways are attributed correctly.

Rules:

- Keep the existing `X-Title` header; user overrides of `X-Title` keep their meaning, and OpenRouter default attribution fields stay present even when the user overrides the old field.
- The OpenRouter provider's default source headers also carry `X-OpenRouter-Title: ZCode` and `X-OpenRouter-Categories: programming-app`.
- Detection reuses `isOpenRouterBaseUrl()` from `@zcode/shared`: parse the provider runtime `baseURL`; scheme must be `https:` and host `openrouter.ai` or a subdomain.
- Coverage: model connectivity checks, Repo Wiki/Git commit-message model requests, and provider headers generated by zcode-cli/bootstrap.
- No OpenRouter-specific headers on non-OpenRouter providers or ordinary ZCode backend business API requests. No `@zcode/protocol` changes. Generated artifacts and historical bundles are not rewritten; source changes flow into future builds.
