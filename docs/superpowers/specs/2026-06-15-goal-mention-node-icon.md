# Goal Mention Node Icon

The `/goal` structured command mention node in the chat input uses the lucide `goal` icon, the same goal semantics as the post-send command chip, goal tool, and goal verification surfaces.

Rules:

- Only the icon path of the goal mention node changes. Command mention color, size, copy, and serialized markdown stay unchanged.
- `/compact` and plain slash command icons are unaffected.

Acceptance:

- The `/goal` mention node renders the lucide `GoalIcon` SVG path.
