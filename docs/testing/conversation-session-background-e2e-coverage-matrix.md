# Conversation Session Background E2E Coverage Matrix

> **Off-peak background revision:** design, Core/protocol evidence and the results of the three OP10 desktop variants are in the [implementation plan](../off-peak-task/background-lifecycle-plan.md#最终验证记录2026-10-08). The cases are still manual-review/pending; full mobile interaction is not verified; this does not change this matrix's original admission and delivery scope.

This document records the E2E enumeration boundary of background runtime tasks in the conversation area. It complements the `BG` group of the main matrix and covers only the desktop main chain that is implemented and confirmed.

> **Coverage status note:** the historical combined spec `conversation-session-background.test.ts` currently sits in `manual-review/pending`, so "covered by" for BG01-BG24 means the candidate spec has the matching assertion, not that these belong to the default E2E gate. The V4 background specs in the current default directory cover only the cases they explicitly reference in-row.

| Goal queue terminal  | Explicit pass as representative                                                   | Direct send of main-idle input; verifier in-flight input is queued; the queue is re-evaluated right after target complete                                                                         | fail-open/cancel, typed goal/compact, mobile replayable go through dedicated matrices                                           | H08/G1-10 + user-reported session runtime trace                 |
