# Model Selection Regression: Product Decision Questionnaire

> 76 items need a decision. This file keeps only product/contract decisions, not items that are already settled and only need test proof.

Fill in the last column directly. Options are A/B/C; if none fits, write the new rule in the last column. Terms used below (the per-row glossary column of the earlier version was folded into this list; it explains terms only and implies no recommended answer):

- picker: the model selection menu. Recent: recently used model. Host preferred: the preferred model of the current Host. family default: default model of a model family. selectable: satisfies config and permissions and can be selected for execution. disabled: model still exists but new requests are forbidden. deprecated: retired. locked: history value can be shown but not selected again.
- draft: local uncommitted selection. intent: the model the user wants. authoritative: confirmed by the runtime or server. sparse selection: stores only explicitly set fields, the rest stay empty.
- Registry: registry of available Providers and models. snapshot: state saved at a point in time. revision: config version. atomic publish: consumers see a complete old or complete new version. partial publish / mixed snapshot: only part published, new and old fields mixed. optimistic: shown by the client before the authoritative side confirms.
- Active Model: the model object currently executing. ModelFactory: runtime factory creating the model object from selection and config. in-flight: started but not finished.
- entitlement: account plan or permission. queued Submission: accepted but not yet started. Automation record: persisted automation task record.
- identity / scope: what makes two objects the same object, and where it applies. workspaceKey: workspace key for identity isolation. legacy / migration: old implementation or data format and moving it to the new one.
