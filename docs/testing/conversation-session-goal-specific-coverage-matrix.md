# Conversation Session Goal Specific Coverage Matrix

This document counts only goal-specific combinations, so the generic running/queue/compact coverage is not miscounted as goal coverage.

Note: the goal-related specs currently moved into `packages/desktop/test/e2e/conversation-session/manual-review/pending/` together with the conversation main path. A `covered` in this file means a historical dedicated setup/action/assert exists; until human review promotes them back to the default path, they do not mean the default conversation quality gate is closed.

The cross combinations of goal and fork are pruned by the fork invariants; see [conversation-session-fork-cross-product-matrix.md](./conversation-session-fork-cross-product-matrix.md).

Status meanings:

| Status      | Meaning                                                                     |
| ----------- | --------------------------------------------------------------------------- |
| `covered`   | A goal-specific setup/action/assert exists                                  |
| `partial`   | Partly covered by an adjacent generic case but lacking goal-specific assertions |
| `missing`   | The product expectation is clear but there is no automation yet             |
| `failing`   | A probe exists but the current implementation does not satisfy it           |
| `undefined` | The product expectation or failure semantics are not confirmed              |
