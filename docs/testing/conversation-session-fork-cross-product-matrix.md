# Conversation Session Fork Cross Product Matrix

This document converges only the fork-related cross combinations and does not enumerate full permutations. Fork product semantics are pruned by three invariants: whether fork is allowed, the copied-history boundary, and inheriting future session state.

Source cases: `E/K/N/P` of [conversation-session-case-catalog.md](../conversation-session-case-catalog.md), and `G3` of the goal-specific matrix.

```text
parent: stable turn S ---- current running turn R ---- future work
               |
               +-- fork(S) --> child: transcript <= S

parent R / queue / background / continuation / shared workspace continue as is
```

## Pruning basis

| Invariant                    | Basis                                                                                       | Description                                                                                                                                                                                                                                                                                                                                                   |
| ---------------------------- | ------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Whether fork is allowed      | Only the last completed assistant segment of a `completedSuccess` product turn is allowed, but the parent session need not be completed | While a primary turn, foreground subagent, goal continuation or goal verifier is running, an earlier stable target can be forked; compact is an operation lock. The current streaming/interrupted/failed partial, a middle assistant segment, user/tool/timeline and a missing stable target are all rejected |
| Copied-history boundary      | The child gets only the stable history at and before the fork point                          | New data resolves the fixed turnId, ordered messageIds and boundaryMessageId from the persisted turn anchor; old data falls back only when unambiguous, otherwise it is rejected. Parent history after the fork point does not enter the child; the tool blocks and the final assistant within the target turn enter the child as a whole on the logical boundary |
| Inheriting future session state | The child inherits the configuration/history state at the fork point and does not copy the parent's future work | Model, thinking depth, provider and the current model's thinking-level capability are inherited from the fork-point runtime snapshot; goal inherits only the target + verifier timeline before the fork point. The parent queue is kept and the child queue is empty; live active/background work, a pending background result and the continuation inbox belong only to the parent session |
| running workspace boundary   | A running fork copies only the conversation and does not rewind the shared workspace         | The parent session and shared files continue as is; the existing workspace checkpoint behavior for completed/idle is not widened in this round                                                                                                                                                                                                              |
| timeline projection          | The fork notice is a turn boundary                                                           | The fork timeline does not enter the assistant working history and is not collapsed by "worked" (已工作)                                                                                                                                                                                                                                                       |

## Combinations not in this matrix

| Combination                                                     | Pruning reason                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Full permutations of queue length `0/1/2/3+`                    | The queue is never copied and the parent queue is kept; only the two classes `queue=0` and `queue>0 held` need proving                                                                                                                                                                                       |
| Full permutations of background bash/subagent count and duration | Live background work is never copied and the parent background result goes back only to the parent session; only the two classes pending and returned-but-not-consumed need proving                                                                                                                          |
| Full permutations of goal with model/thinking depth             | They are all session-level future state and the inheritance basis is covered by `FX01` and `FX03` respectively                                                                                                                                                                                               |
| Full permutations of every provider / model x fork              | The capability list is authoritatively projected from the child runtime's current model; `FX11` suffices with a "non-generic five-level" representative. The desktop local completed path proves the product semantics; mobile replayable, SSH/WSL/Docker and running fork do not extend the state combinations again and only need the protocol snapshot/delta to share the same field |
| Every session-scoped tab x fork x each client/theme/language    | `FX12` uses the auxiliary-conversation tab + desktop continuous to represent the common renderer branch of `visibleTabs=[]`; subagent/plan etc. types are not repeated, and remote/mobile with replayable and theme/locale are not crossed                                                                    |
| primary / foreground subagent / goal continuation / goal verifier x all target shapes | `FX06` proves with a running-phase representative that an earlier stable target can be forked, and `FX10` uses an unclosed target as the negative representative                                                                                                                         |
| Full permutations of every tool name with fork                  | The tool cross product is owned by [conversation-session-tool-cross-product-matrix.md](./conversation-session-tool-cross-product-matrix.md); the fork matrix keeps only the history-boundary regression `FX08`, where one visible assistant merges several raw assistants                                      |
| edit followed by goal/queue/model                               | edit only changes the active-branch history boundary of fork; goal/queue/model are covered by `FX01`, `FX03`, `FX07` respectively, with no full permutation                                                                                                                                                   |
| Fork in a fault state caused by failed compact / network error / disk error | Belongs to the environment-fault catalog; this matrix only pins that a failed/error partial is not a forkable product final state                                                                                                                                                                  |
