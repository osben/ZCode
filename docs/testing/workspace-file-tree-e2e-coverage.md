## Coverage decisions

| Decision                                                           | Status   | Reason                                                                                                                                                                                                                                                                  |
| ------------------------------------------------------------------ | -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Local desktop + multi-level compact folders + expand + scroll down | accepted | Covers physical depth, display offset, virtual scrolling and sticky ancestor selection together; the minimal complete chain of this regression.                                                                                                                         |
| Ordinary directories (no compaction)                               | pruned   | The existing tree expand path and helper/unit tests cover ordinary depth; they cannot prove this compact offset regression.                                                                                                                                             |
| Zai Light / Zai Dark run separately                                | pruned   | Guide lines and indentation share the same DOM and design tokens; the case asserts structure and geometry, not theme pixel screenshots.                                                                                                                                 |
| Web / mobile Web repeat                                            | pruned   | `WorkspaceFileTreeRowView` is a shared rendering implementation; the case involves no platform service, remote delivery or touch-specific behavior.                                                                                                                     |
| SSH / WSL / Docker workspace                                       | pruned   | The defect is in renderer display depth; remote file reads and `workspaceIdentity` isolation are outside this case's behavior boundary.                                                                                                                                 |
| Full default filter matrix                                         | pruned   | `.git`, `node_modules`, `.env`, hidden-directory descendants and build output filters are covered by service unit tests and the file-search filter E2E; the shared-search case only proves it reuses the same index and ranking and does not copy blacklist assertions. |

## Out of scope

- Adding a file to a deep directory that was never loaded keeps lazy-load semantics and need not show automatically.
- A loaded but collapsed directory does not keep a long-lived watcher; such directories rely on the refresh button to update the cache, so the number of OS watchers does not grow without bound with browsing history.
- Watcher behavior of remote workspace / Web remote is not proven by the local desktop file tree cases.
- Fallback polling after the OS-level `fs.watch` misses events is not a semantic of this round.
- Watcher caps and resource backoff for many expanded directories are evaluated separately.
