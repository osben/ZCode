### R08 Continuation Plan (continues Todo83's arbitrated hierarchy, no new persistence)

```text
Family connection preferences + account queries
   -> Account status (availability/current/effectiveAt)
      + Account Config Overlay (entitled/model members)
   -> Same Account Source snapshots, same revision
      -> Settings can view pending/non-current connections
      -> Registry only accepts current connection's executable models
```

Rules: `current` stays a runtime fact; Off-Peak has no current; unselected plans are not written as unentitled. Unknown queries preserve same-account previous facts; explicit pending clears execution eligibility but keeps effective time; empty models clear model members without reusing old whitelists. Plan display queries must not require the plan to be the current model-request connection — read-only viewing and execution-period credential checks are separate. Teams without a specific organization/project identity must not guess a team to infer entitlements: stay unknown and provide concrete identities through existing subscription product entries.
