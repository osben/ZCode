## Shared And Divergent Behavior

- UI component styles unchanged; ordinary new tasks and share imports share default selection rules, but only first import carries the initialization source flag.
- ModelSelectionView remains the validity source; explicitly empty selections and temporarily invalid saved drafts are never filled with a default model.
- Import only produces a Renderer draft; Host atomic import and the execution config submission boundary are unchanged; an unusable model does not block opening content.
- The off-peak model source stays hidden and never enters the ordinary task model catalog; ordinary API / package / Start capabilities do not change with off-peak.
- Security validation admission is expanded, but entering validation still depends on the switch and existing retry / fallback — hitting the domain does not inevitably enter validation.
