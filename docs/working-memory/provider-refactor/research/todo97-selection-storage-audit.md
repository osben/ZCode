## Deletions / Retentions Reasons

- Deleted: Markdown intermediate-state dual-read/write branches, full-profile memory Provider conversions, Hosts' old universal parsers. Formal Markdown codecs and JSON schemas are separate.
- Retained: internal/protocol structured ModelSelections; built-ins JSON's new maps are not Markdown intermediate states; history-message display hydration projections and truly-old-data importers — none can re-become current-selection backup sources.
- Whether an old format is a shipped base is judged by staging's actual writing points (Session thoughtLevel entries and Bot v2 both genuinely existed) — not batch-deleted by whether a field looks new or old.
- Files change only in user directories; no global "migration-complete" markers (late-joining old files are not missed); file locks, original-text comparison, permissions, and symbolic-link boundaries are handled by shared Node entry points. Plain requests never call migrations and never secretly change Providers.
